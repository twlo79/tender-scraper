- **做法**：問題 1 恢復後，比對 GitHub Actions runner 實際抓到的 HTML（目前本環境被 WAF 擋無法直接比對），確認這 3 站是否其實有穩定的 table 結構可直接用原生 selector 解析（07-20 的 30/11/2 筆證明原生 parser 平時是能運作的，只是本次不知道是站方結構改了還是純粹恰好觸發 fallback），把「必須依賴 Claude 才有數字」的來源數量降到 0。
- **預期效果**：Claude API 未來再次中斷時，不會讓 3 個來源同時斷線 6 天以上。

**建議 2（延續）：修問題 2（台鐵地區篩選漏洞）——已有實際外洩案例，且修法與新增來源相比成本更低**

- **依據**：07-28 已實際推播「【臺北營業分處】【土地出租】【新竹縣新豐鄉明新段111、113地號部分土地】」，是本業務目標（雙北租賃）明確不該出現的推播內容，且截至今日（08-02）已 5 天未修，隨時可能再次發生。

**建議 3（延續）：台北市都發局近 31 天 fetch 破百却 `new` 恆為 0，疑似抓到過期存檔頁而非最新公告頁**
