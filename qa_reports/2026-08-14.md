### 問題 2（新定位，此前僅在總覽表提及未深入）：台北自來水處／土地銀行 date 欄位 100% 空白，已定位到具體程式碼問題

- **定位**：
  - `parse_taipei_water()`（`scraper.py:157`）：
    ```python
    date_td = td_map.get("公告日期") or td_map.get("發布日期") or td_map.get("日期")
    dt = date_td.get_text(strip=True) if date_td else ""
    ```
    這段靠 `<td data-title="公告日期">` 等三個精確字串比對日期欄位；同一函式的標題／url 擷取（`title_td`／`<a href>`）用的是不同邏輯（找含 `<a>` 的儲存格），仍然正常運作，只有這段日期欄位比對持續失敗，最可能是台北自來水處官網目前的 `data-title` 屬性值已改成非這三者之一。
  - `parse_landbank()`（`scraper.py:613`）：
    ```python
    dt = tds[-1].get_text(strip=True) if tds else ""
    ```

- **建議修法**（兩者都改用已存在的 `_extract_dates()` 從整列文字備援擷取日期，屬低風險最小改動，不需要事先知道即時 HTML 的精確欄位名稱）：
  ```diff
  --- a/scraper.py
  +++ b/scraper.py
  @@ parse_taipei_water()
           date_td = td_map.get("公告日期") or td_map.get("發布日期") or td_map.get("日期")
           dt = date_td.get_text(strip=True) if date_td else ""
  +        if not dt:
  +            # data-title 對應失敗時，退回整列文字讓 is_within_date_window() 的
  +            # _extract_dates() 從中掃描日期樣式
  +            dt = row.get_text(" ", strip=True)
           if title and len(title) > 3:
  ```
  ```diff
  --- a/scraper.py
  +++ b/scraper.py
  @@ parse_landbank()
  -        dt   = tds[-1].get_text(strip=True) if tds else ""
  +        dt   = tds[-1].get_text(strip=True) if tds else row.get_text(" ", strip=True)
  ```
  這兩處改動只在原本抓不到日期時才啟用備援，不影響目前已正常運作的情況，風險低。
- **是否已修**：未修。本環境出網受限，無法對 `water.gov.taipei`、`landbank.com.tw` 發出請求驗證（皆回傳 proxy 403），依規則需在有網路權限環境用 `dry_run_all_regions.py --debug --source <來源>` 驗證通過才算完成，故僅提供 diff。
