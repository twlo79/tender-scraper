### 問題 27（**新增**）：政府採購網地區篩選以「機關名稱」而非「不動產所在地」判定，導致非雙北物件被推播

- **現象**：今日（2026-09-24）政府採購網推播 6 筆中，第 5、6 筆為：
  ```
  新北市平溪區十分段1269地號部分土地標租案
  基隆市安樂區西定段326-2地號部分土地(土地供設置電動汽車公共充電樁)標租案
  ```
  第 6 筆 title 已明確寫出物件座落於「**基隆市**」，完全不屬於「雙北地區的公有不動產」業務目標，但仍通過篩選並真實推播給使用者。
- **根因分析**：`passes_filters()`（`scraper.py:820-838`）的地區判定為：
  ```python
  text = title + agency
  if regions and not any(k in text for k in regions):
      return False
  ```
  這裡 `regions = ["台北","臺北","新北","瑠公管理處"]` 是用 **OR** 邏輯比對 `title + agency` 合併字串——只要「機關名稱」（announcing agency，`tds[1]`）含「新北」等字（例如該案由新北市政府某單位對外招租、但轄有的資產實際座落於基隆市），即可讓一筆 title 已明確自報為「基隆市」的案件通過篩選。也就是說，**篩選邏輯把「發文機關在雙北」誤當成「不動產本身在雙北」**，兩者對政府採購網這種全國性資料來源而言並不等價（雙北市政府、國營單位皆可能持有轄區外資產）。
  （sandbox 網路被擋，無法即時抓取此筆原始 `agency` 欄位值做逐字元核對，但 title 本身已足以確認「此物件不在雙北」這個結論，不影響修法方向的判斷。）
- **建議修法**：當 title 中已明確出現其他縣市名稱、且未同時出現雙北關鍵字時，應直接判定不通過，不再讓 agency 的雙北字樣覆蓋 title 的明確地點聲明：
  ```diff
   def passes_filters(item: dict) -> bool:
       """套用 GLOBAL_FILTER 的白名單、黑名單、地區篩選（所有來源共用）。"""
       title  = item.get("title", "")
       agency = item.get("agency", "")
       text   = title + agency

       regions = GLOBAL_FILTER.get("regions", [])
  +    OTHER_CITIES = [
  +        "基隆市", "桃園市", "新竹市", "新竹縣", "苗栗縣",
  +        "台中市", "臺中市", "彰化縣", "南投縣", "雲林縣",
  +        "嘉義市", "嘉義縣", "台南市", "臺南市", "高雄市",
  +        "屏東縣", "宜蘭縣", "花蓮縣", "台東縣", "臺東縣",
  +        "澎湖縣", "金門縣", "連江縣",
  +    ]
  +    if regions and any(k in title for k in OTHER_CITIES) and not any(k in title for k in regions):
  +        return False
       if regions and not any(k in text for k in regions):
           return False
  ```
- **是否已修**：未修，依規則僅提出定位與 diff，待人工核准。
- **驗證方式（待有網路權限環境）**：`python dry_run_all_regions.py --source 政府採購網 --debug`，確認此 diff 套用後「基隆市安樂區...」不再出現於通過清單，且既有雙北案件（如「第2次公開標租臺北市中正區...」）仍正常通過。

### 問題 28（**新增**）：Google Alerts 推播「投標單」表單名稱，疑似非具體案名

- **現象**：今日 Google Alerts 推播「臺北市政府財政局標租市有非公用不動產**投標單**」。對照同日由政府採購網／台北市財政局正確推播的案名（如「第2次公開標租臺北市中正區中華路2段409巷5弄4號等18戶市有不動產」），這筆標題明顯是 Google 索引到的**投標單/表單頁面標題**，而非公告本身的案名，屬於 QA 檢查項目 8 描述的「分類名稱/導覽文而非真正案名」情況。
