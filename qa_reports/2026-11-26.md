## 二、異常與處理
### 問題 1：政府採購網連續 7 天 HTTP 500（延續，剩 3 天補救期）
- 現象：11/19–11/25 每天 0 筆。11/25 log：`readArpam?searchAssetsName=出租&searchBeginNoticeDate=2026/11/15&searchEndNoticeDate=2026/11/25&pageModel.rowsPerPage=100` 回 `500 Internal Server Error`，`標租` 也一樣
- 定位：PCC 端點或參數變了的可能性最高。`_arpam_debug()`（`scraper.py:466`）只在 `DRY_RUN` 時執行（`scraper.py:540-541`），#186–#190 都是 `DRY_RUN: false`，所以診斷一次都沒在 Actions 跑過
- 建議修法（擇一）：
  1. 手動觸發 workflow 並勾 `dry_run`，看 log 的 `[PCC DEBUG]` 段落
  2. 拿掉 DRY_RUN 條件，讓明天的正式 run 就印出診斷：
     ```diff
     @@ scraper.py:540
     -        if DRY_RUN:
     -            _arpam_debug(keyword, start, end)
     +        _arpam_debug(keyword, start, end)   # 只印 log，不影響推播
     ```
- **時限**：日期窗 10 天，11/19 以來的案件要在 **11/29 前**修好才補得回來，剩 3 天（今天、11/27、11/28 三次 run）
- 是否已修：未修（沙箱連不到 PCC，依規則不自動改碼）

### 問題 2：國有財產署批次公告標題資訊不足（新）
- 現象：11/25 推播「【招標公告】北區分署 115年第22批 招標公告 公告:115年11月25日 開標:115年12月10日」。標題由 `scraper.py:453` 用欄位組成，`種類`欄跟分類名一樣都是「招標公告」，標租還是標售、標的物在哪個區都看不出來
- 定位：國產署的招標公告是整批公告，標的物明細在 msgId 詳細頁裡；parser 只讀列表頁
- 建議修法：先在可連外網的環境跑 `python dry_run_all_regions.py --debug --source 國有財產署`，看詳細頁有沒有「標租／標售」字樣和標的物地址；如果有，再加一個詳細頁抓取，把類型補進 title，例如 `【招標公告·標租】北區分署 第22批（新北市…）`，標售批次則交給黑名單或略過
- 是否已修：未修
