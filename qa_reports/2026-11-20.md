## 二、異常與處理
### 問題 1：政府採購網 11/19 fetched=0（新問題）
- 現象：11/19 run 政府採購網 0 筆，前 7 天每天 51–74 筆。這是目前最有產出的來源：11/11–11/19 共 13 則推播，有 7 則來自這裡
- 定位：`daily_report.json` 11/19 的 errors 有兩筆：`[政府採購網/財物出租/出租]` 和 `[政府採購網/財物出租/標租]` 都是 **`500 Server Error: Internal Server Error`**，網址是 `https://web.pcc.gov.tw/opas/arpam/public/readArpam?...`。所以是對方伺服器出錯，不是 selector 失效，也不是被擋（被擋通常是 403 或 timeout）。`_arpam_fetch_keyword()`（`scraper.py:418-427`）只呼叫一次 `requests.get`，失敗就直接回空串列，沒有重試

- 建議修法：(1) 看今天（11/20）的 run，政府採購網如果回到 50 筆左右就是暫時故障，不用處理；(2) 不論結果，在 `_arpam_fetch_keyword` 加重試，讓單次的 5xx 不會讓整天的資料歸零：

## 三、優化建議
### 建議 1：所有外部請求加重試（優先處理政府採購網）
