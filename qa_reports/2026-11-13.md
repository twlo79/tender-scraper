### 問題 1：台鐵「臺北營業分處」的外縣市停車場案件持續漏網（第 3 次）
- 現象：11/12 推播新竹香山停1 停車場標租，非雙北，也不是不動產租賃目標
- 定位：已從程式碼確認。`passes_filters`（`scraper.py:824-842`）的地區比對用 `title + agency`，而台鐵標題開頭固定是 `【臺北營業分處】`，含「臺北」，所以台鐵臺北分處轄區（基隆、新竹等）的案件都會通過地區篩選。另外黑名單沒有「停車場」，所以 `【停車場標租】` 也擋不掉
- 建議修法（`scraper.py`）：
```diff
@@ def passes_filters(item: dict) -> bool:
     title  = item.get("title", "")
     agency = item.get("agency", "")
-    text   = title + agency
+    # 去掉「XX營業分處／分署」這類機關標籤，避免轄區名稱（臺北營業分處）誤判成雙北
+    clean_title = re.sub(r"【[^】]*(分處|分署)】", "", title)
+    text   = clean_title + agency
+
+    OTHER = ["基隆", "新竹", "桃園", "苗栗", "臺中", "台中", "彰化", "南投", "雲林",
+             "嘉義", "臺南", "台南", "高雄", "屏東", "宜蘭", "花蓮", "臺東", "台東", "澎湖", "金門", "連江"]
+    if any(k in clean_title for k in OTHER) and not any(k in clean_title for k in GLOBAL_FILTER["regions"]):
+        return False
@@ GLOBAL_FILTER["blacklist"]
-        "財物採購", "勞務採購",
+        "財物採購", "勞務採購", "停車場",
```
  注意：台鐵 item 的 agency 如果也含「臺北」，第一段 regions 比對還是會通過，所以重點在 OTHER 排除那一段。
