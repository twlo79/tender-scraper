  1. 手動跑一次 workflow 並勾 `dry_run`，看 log 的 `[PCC DEBUG]` 段落找出可用參數
  2. 或把 `scraper.py:540` 的條件拿掉，讓正式 run 失敗時也印診斷 log：
     ```diff
     @@ scraper.py:540
     -        if DRY_RUN:
     -            _arpam_debug(keyword, start, end)
     +        _arpam_debug(keyword, start, end)   # 每次 run 只跑一次，只印 log
     ```
- **時限**：11/19 起漏掉的案件須在 **11/29 前**修好才補得回來（日期窗 10 天），剩 5 天
