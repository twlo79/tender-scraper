## 二、異常與處理
### 問題 1：台北自來水處 11/14 fetched=0（DNS 暫時失敗）
- 現象：前 7 天每天都抓到 20 筆，11/14 是 0
- 定位：`daily_report.json` 11/14 errors 有 `NameResolutionError: Failed to resolve 'www.water.gov.taipei' ([Errno -3] Temporary failure in name resolution)`。這是 Actions runner 的 DNS 暫時失敗，不是 parser 失效。沙箱裡沒辦法重新抓（proxy 403），所以沒辦法用 dry run 驗證
- 建議修法：`get()` 沒有重試，只要一次網路失誤，該來源當天就會變 0。可以加一次重試：
  ```diff
  --- scraper.py:100
   def get(url, **kwargs) -> requests.Response | None:
  -    try:
  -        r = requests.get(url, headers=HTTP_HEADERS, timeout=20, **kwargs)
  -        r.encoding = r.apparent_encoding or "utf-8"
  -        return r
  -    except Exception as e:
  -        log.warning(f"GET 失敗 {url}：{e}")
  -        return None
  +    for attempt in range(2):
  +        try:
  +            r = requests.get(url, headers=HTTP_HEADERS, timeout=20, **kwargs)
  +            r.encoding = r.apparent_encoding or "utf-8"
  +            return r
  +        except Exception as e:
  +            log.warning(f"GET 失敗（第 {attempt+1} 次）{url}：{e}")
  +            if attempt == 0:
  +                time.sleep(5)
  +    return None
  ```
  （需要確認 `time` 已經 import）
- 是否已修：未修。11/15 的 run 如果自來水處還是 0，就要升級處理
