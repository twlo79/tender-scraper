## 三、優化建議

### 建議 1（方向 A，新發現）：Google Alerts 來源以網域比對補強地區判定，避免雙北案件因標題無地名而被誤殺
- 依據：`state.json`「Google Alerts」300 筆歷史記錄中，153 筆同時符合白名單且未觸黑名單、卻被 `regions` 篩選擋下（多為外縣市案件，篩選正確）；但逐筆核對 url 網域後，其中 **4 筆**實際來自新北市政府/學校網域（`ruifang.ntpc.gov.tw` 瑞芳區公所、`sanchong.ntpc.gov.tw` 三重區公所、`tfon.ntpc.edu.tw`、`bhes.ntpc.edu.tw` 兩所學校），標題分別為「太陽光電發電系統公開標租案租賃標的清冊」「115年8月本市現代化公有零售市場攤位標租公告」「設置太陽能光電風雨球場暨太陽光電發電系統公開標租案」「設置太陽光電發電系統公開標租案投標標價清單」——因標題未寫「新北」、且 Google Alerts parser 未填 `agency` 欄位，全數被地區篩選誤殺。
- 做法：`scraper.py` 的 Google Alerts 分支在建立 item 時，增加以 url 網域比對雙北關鍵字（如 `ntpc.gov.tw`、`ntpc.edu.tw`、`gov.taipei`、`tp.edu.tw`）、命中則將對應地名寫入 `agency` 欄位（或另開一個 `passes_filters()` 的網域白名單旁路），使其能通過 `regions` 判定。範例：
  ```diff
   # Google Alerts 組 item 處，加入網域→地名映射
  +NTPC_DOMAIN_HINTS = ("ntpc.gov.tw", "ntpc.edu.tw")
  +TAIPEI_DOMAIN_HINTS = ("gov.taipei", "tp.edu.tw")
  +def infer_region_from_url(url: str) -> str:
  +    if any(h in url for h in NTPC_DOMAIN_HINTS):
  +        return "新北市"
  +    if any(h in url for h in TAIPEI_DOMAIN_HINTS):
  +        return "台北市"
  +    return ""
   ...
       item["agency"] = item.get("agency", "") + infer_region_from_url(item.get("url", ""))
  ```
- 預期效果：至少補回 4 筆已知的雙北租賃案（目前皆已过滤到 300 筆歷史記錄裡未推播，屬於已发生的漏放，非假設情境），且此規則只在網域命中時附加地名、不放寬其他判定，不會引入新噪音。
